# BeanBound

BeanBound is a travel-first specialty coffee finder. It keeps the recommendation spirit of RoastRegister, but ranks nearby cafes by distance before considering latte art, workspace, pastries, and in-house roasting.

## Preview

From the repository root, run a local static server and open `/beanbound/`.

## MVP features

- Browser geolocation with city-search fallback
- Nearest-first cafe ranking and adjustable radius
- Rating categories for worth a walk, drive, or road trip
- Feature filters for latte art, laptop space, pastries, and roasting
- Responsive visual map with recommendation pins
- Multi-photo review galleries and a lightbox viewer
- Saved cafes stored locally in the browser
- Directions links and lightweight analytics events

The initial catalog is intentionally illustrative. Production work should replace it with live venue data, verified hours, current review imagery, and a photo-rights workflow.
